## 人工评分

在每题 `human_review` 中填 `pass` / `fail` / `na`，未评留 null：

| 字段 | 判断标准 |
|---|---|
| factual_support | 每项回答事实与所提供证据一致，条件和传说限定不丢失 |
| citation_support | 引用摘录确实支持对应说法，不能只靠来源编号存在 |
| poi_isolation | 未把另一景点的政策或设施套用到目标；明确比较则逐景点区分 |
| refusal_correct | 缺证据时拒答/澄清，有充分证据时不无故拒答；允许恰当部分回答 |
| freshness_correct | 采集公告、价格、状态未被表述为实时保证，有采集时间/官方核对提示 |
| point_coverage | 必须要点和重要条件完整；应拒答题是否说明真正的信息缺口 |

`na` 只用于确实不适用的维度，例如完全拒答没有引用时引用支持可记 na；拒答正确性仍应评分。需要给 `notes` 写判断证据，失败题在 `attribution` 中记录 retrieval / generation / data / mixed / unknown。

**归因步骤**：先看原始 Top 5，再看参考资料。

1. 参考内容存在，但 Top 5 未找回所需证据：检索问题。参考来源未出现只是诊断线索，需先排除替代片段也足够的情况。
2. Top 5 足够，答案却错误、遗漏条件、混用景点或不当拒答：生成/提示词/回答校验问题。
3. 数据没有所需信息、相互矛盾、过时或内容可疑：数据问题。此时正确拒答不应扣系统分。
4. 两层以上共同导致，记 mixed；无法判断，记 unknown。

**不把“返回 answered”“拒答标签一致”或“参考片段检索到”当准确率**。当前报告诊断字段都不是评分，未完成人工审核的题不计为通过。题集只有25题，结果只能作为初期证据，不足以证明生产质量；报告应同时给出审核题数、各维度失败数、分类结果与具体失败案例。

## 首轮结果（2026-10-12）

首次结果为 `rag/eval/reports/answer_holdout_v1_2026-10-12_run1.json`，阅读评分表为同名 `.md`。25题均获得响应，19题 answered、6题 insufficient_evidence；初次采集时人类审核0题，准确率为 null。所有参考片段与远端数据库内容一致，运行前后代码、Prompt、题集、数据及向量摘要未改变。

代理初步阅读标记的待人工复核项，不计作已完成评分：

- 15题：回答复述两档儿童政策，没有直接明确“10岁、1.3米适用优惠票”，应检查要点覆盖和回答直接性。
- 07题：旧攻略与夜场结束公告冲突，答案引用了结束公告且说明未知年份/时效；还需检查“采集记述”是否在正文足够清楚、路线原文是否存在自身矛盾。
- 18题：已经说明需要一名成人陪同，限制部分另说“未说明陪同成人具体人数上限”，容易令读者困惑，需要审核表达是否自相矛盾。
- 25题：正确不保证指定日期全项目开放，但额外列出许多游乐设施；检查是否属于不必要展开。
- 02题：参考要点中“河图文化”是否为题目所需的强制点，需人类校准标签，不能把未问到的补充信息机械计为遗漏。

本轮没有依据这些观察修改模型、Prompt、检索或源数据。
